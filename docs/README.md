# Rendering image for a rendering competition
This repository consists of all materials needed to describe the final scene for a rendering competition.

## Final render
![Night Rider](/render.jpg)
Achieved 6th place out of 36 submissions. Final standings will be available [here](https://graphics.cg.uni-saarland.de/courses/cg-2025/index.html).

## Renderer
The renderer has been developed as part of the computer graphics course at the University of Saarland. See [renderer] repository for more information.

## 3D Modeling
`supra.blend` contains full description of the 3D scene modeled in blender. The main part of the scene, that is the car, has been modeled completely from scratch.

## Webpage
The final render is to be submitted along with a [webpage](https://gatemrou.github.io/rendering-comp/#) which presents the workflow. 
In addition, please see the same page for more information regarding the project.
